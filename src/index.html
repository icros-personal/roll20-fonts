Roll20 dice-font diagnostic

This page tests whether your browser can display Roll20's dice font, and if not, narrows down why. It bundles Roll20's font for testing purposes only (sorry, I'm trying to help).

What to send back

  1. Wait a few seconds for the checks below to finish.
  2. Click Copy report and paste it to me (or copy the text box manually).
  3. Take a screenshot of the whole page.
  4. Open the console (Ctrl+Shift+K), and copy anything mentioning “downloadable font”.
  5. Tell me which browser add-ons you use (uBlock, NoScript, etc.).

1. Automated checks

“Actually rendered?” compares the text's width against fallback fonts, so it shows whether the font was really drawn, not just downloaded. The probe font is a tiny self-made font (A = square, B = diamond, C = triangle, D = ring).

2. Visual samples

These should look like dice faces (Roll20 font) and simple shapes (probe font). If you see ordinary letters, the font is not being used.
